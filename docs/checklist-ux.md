# 체크리스트 — 사장 시점 불편 점검과 수정 (2026-09-05)

목표: 결혼정보회사 사장이 weddingCORE를 쓰다가 막히거나 답답하거나 말이 어려운 곳을 찾아 고친다.
찾는 일은 영역별 점검 15개를 백그라운드로 돌려 `docs/ux-audit/`에 모은다. 고치는 일은 이 파일에서 순서대로 진행한다.

## 1차 발견 (2026-09-05 오후, 코드 검토 + 공개 화면)

### 당장 막히는 것
- [x] 비밀번호 찾기가 없다 → 로그인 화면에 재설정 메일 보내기 추가
- [x] 가입 때 비밀번호 확인 칸이 없다 → 두 번 입력해 대조
- [x] 로그인 실패 문구가 영어 오류 코드 → 우리말로 바꿔 보여준다 (`authErrorMessage`)
- [x] 고객 기본정보(이름·전화·주소·소득 등)를 고칠 수 없다 → 상세의 「정보 수정」(등록 창 재사용)
- [x] 끝난 고객을 목록에서 내릴 수 없다 → 상세의 「종료 처리」(완료·취소·사유), 목록 「종료된 고객」, 되돌리기
- [x] 성별 「남」·혼인이력 「미혼」이 기본 선택이라 여성·재혼 고객이 잘못 저장된다 → 「선택」으로 비움 (점검 03)
- [x] 전화번호로 고객을 못 찾는다 → 뒷자리 검색, 목록에 번호 표시 (점검 03)
- [x] 올린 서류를 지울 수 없다 → 삭제(파일과 기록 함께, 확인 단계)
- [x] 서류 업로드 경로가 저장 규칙과 안 맞아 올라가지 않는다 (점검 05) → 경로를 `documents/{문서id}/{파일명}`으로, 규칙은 하위 전체 허용
- [x] 가입 중 등록증 주소 읽기가 규칙에 막힌다 (점검 01) → 가입 중인 본인도 읽기 허용
- [ ] 비자 사건 단계를 바꿀 수 없다 → 목록에서 단계 변경
- [ ] 캐럿 「계좌이체로 신청」이 항상 거부된다 (규칙은 pack_50/200/500, 화면은 pack_110/330/550) → 규칙을 화면 값에 맞춘다

### 매일 쓰면서 답답한 것
- [ ] 대시보드 「기한 경고」·「법적 위반」 카드를 눌러도 목록이 걸러지지 않는다 → `filter=overdue` 처리
- [ ] 알림 빨간 점이 안 꺼진다 → 열면 읽음 처리 (규칙이 write:false라 서버 함수 필요)
- [ ] 접수 상태가 「접수」면 바로 고객 등록을 못 한다 → 「고객으로 등록」을 항상 보이게
- [x] 고객 등록 때 연소득이 필수 → 선택으로, 만원 환산 표시. 상세에는 「아직 확인 전」
- [ ] AI 문서 동의에 「동의서 문서번호」를 요구하는데 동의서 양식이 없다 → 양식 제공 또는 문구 변경
- [ ] 업체 정보 삭제가 확인 없이 즉시 → 확인 단계
- [ ] 마케팅 「검색 준비도」가 고정값 → 실제 값으로 계산하거나 뺀다
- [ ] 매칭 상대방을 넣을 곳이 없어 궁합 카드가 늘 비어 있다 → 설계 필요(범위 큼, 뒤로)
- [ ] 휴대폰 하단 메뉴 9개가 옆으로 밀린다 → 줄이거나 「더보기」

### 말이 어렵거나 불안하게 하는 것
