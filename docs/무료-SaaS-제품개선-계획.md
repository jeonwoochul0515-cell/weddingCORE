# weddingCORE 무료 SaaS 제품 개선 계획

> 확정일: 2026-09-05
>
> 업체용 기본 SaaS는 무료로 배포한다. 가입비·설치비·월 구독료·고객 수 과금은 두지 않는다.
> 실제 비용이나 전문 인력이 필요한 AI 문서, 변호사 검토·대행, 마케팅 같은 선택형 서비스만 유료다.

## 제품 위치

weddingCORE는 범용 매칭 프로그램이 아니라 국제결혼중개업체의 고객, 소개, 법정의무,
서류, F-6, 전문가 검토를 연결하는 무료 업무 운영체제다.

## 구현 원칙

1. 엑셀·종이·카카오톡에서 옮겨 오기 쉬워야 한다.
2. 직원이 오늘 할 일을 고객별로 바로 알 수 있어야 한다.
3. 소개부터 만남, 양측 피드백, 재매칭까지 기록이 끊기지 않아야 한다.
4. 신상정보와 서류는 공개 링크보다 인증·권한·감사기록을 우선한다.
5. 무료 기능을 고의로 불편하게 만들지 않는다. 유료 기능은 실제 원가나 전문업무가 있는 경우에만 둔다.

## 단계별 실행

### 1단계 — 기존 자료 이전과 영업 흐름

- [ ] 엑셀에서 저장한 CSV 고객명단 일괄 가져오기
- [ ] 가져오기 전 오류·중복 확인과 미리보기
- [ ] 소개 → 만남 예정 → 만남 완료 → 피드백 → 재매칭/성사 단계 관리
- [ ] 한국 측·외국 측 피드백과 다음 조치일 기록
- [ ] 전화·문자·상담·방문·메모 이력과 담당자·다음 일정 기록
- [ ] 대시보드에 매칭·상담 운영 통계 표시

### 2단계 — 고객 참여

- [ ] 고객별 제출 요청 체크리스트
- [ ] 만료되는 일회용 링크 또는 본인인증을 거친 고객 서류 제출함
- [ ] 업로드 완료 알림과 요청 항목 자동 연결
- [ ] 개인정보 동의 철회·접근 만료·감사기록

공개 업로드 링크는 주소를 아는 사람 누구나 파일을 볼 수 있는 구조로 만들지 않는다. 토큰 만료,
파일 종류·크기 제한, 악성 파일 검사, 제출자 확인, 저장 경로 격리를 설계한 뒤 구현한다.

### 3단계 — 외부 연결

- [ ] 카카오 알림톡·문자·이메일 발송 및 이력 연결
- [ ] 전자계약·서명 서비스 연동
- [ ] 캘린더 연동과 담당자 알림
- [ ] 선택형 부가서비스 카드 결제

기본 SaaS 정기구독 결제는 만들지 않는다. 결제는 AI 캐럿, 전문가 검토·대행, 마케팅처럼
업체가 선택한 부가서비스 주문에만 사용한다.

## 완료 기준

- 처음 쓰는 업체가 CSV 파일 하나로 기존 고객을 옮길 수 있다.
- 매칭 한 건을 열면 현재 단계, 양측 반응, 다음 조치가 한눈에 보인다.
- 고객 상세에서 모든 전화·상담·메모와 다음 약속을 시간순으로 확인할 수 있다.
- 대시보드에서 새 접수, 진행 고객, 기한 위험, 피드백 대기, 재매칭 필요 건수를 확인할 수 있다.
- 외부 고객 서류 제출 기능은 인증·만료·권한·감사기록 검증을 통과하기 전 공개하지 않는다.
