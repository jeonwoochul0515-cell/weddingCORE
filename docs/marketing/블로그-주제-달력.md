# 블로그 글 자동 발행 — 주제 달력 (2026-09-04)

마케팅 센터 「블로그 글 자동 발행」(월 8건 · 10만 원)의 주제 배분과 발행 시기다.
홈페이지용 8건과 네이버 블로그용 8건을 같은 주제로 **다르게** 쓴다(유사문서 회피).
근거는 네이버 검색광고 키워드도구·데이터랩 실측(2026-08 월간, 우리 계정 API)과
우리결혼중개 리서치(`woori/docs/persona-research.md`).

읽는 법.
- 손님은 **나라**와 **비용·절차**로 들어온다. 나이는 검색어에 넣지 않는다. 나이는 제목이 아니라 본문 안의 사례로 다룬다.
- 베트남이 압도적이지만 우즈베키스탄·몽골·캄보디아도 500건대다. 나라를 돌아가며 쓴다.
- 지역 검색(부산국제결혼 220)은 작지만 전환이 높다. 업체 소재지 + 국제결혼을 매달 1건 넣는다.

## 2. 월 8건 배분 규칙

| 자리 | 주제 축 | 건수 | 제목 예 |
|---|---|---:|---|
| 1~2 | 베트남 | 2 | 베트남 국제결혼 총비용 항목별 정리(2026년 기준 예시), 베트남 맞선 여행 일정은 어떻게 되나 |
| 3~5 | 나라 순환 (우즈베키스탄·몽골·캄보디아·필리핀·중국·태국) | 3 | 캄보디아 국제결혼은 만 50세 미만만 가능한 이유, 우즈베키스탄 결혼 절차와 종교 합의 |
| 6 | 비용·환불 | 1 | 국제결혼 계약 전에 확인할 환불 조건 표 |
| 7 | 절차·비자 | 1 | 결혼이민(F-6) 비자 소득 기준 2026년, 배우자 입국까지 걸리는 기간 |
| 8 | 사기·계약·법 또는 지역 | 1 | 등록된 결혼중개업체 확인하는 법, 부산 국제결혼 상담 전에 준비할 것 |

- 나라 순환은 6개국을 두 달에 한 바퀴 돈다(월 3건). 업체가 실제로 진행하지 않는 나라는 뺀다.
- 지역 글은 업체 소재지 기준. 두 달에 한 번은 8번 자리를 지역 글로 쓴다.
- 가족 설득(부모님께 말씀드릴 때, 자녀가 있는 재혼)은 명절 달에 6~8번 자리 하나를 바꿔 넣는다.

## 3. 발행 시기

남성 관심도 최고월은 설·추석 앞뒤다(2025-03, 2025-01, 2024-10, 60대 이상은 2025-08).
가족 압박과 외로움이 겹치는 시기라 **1~3월, 8~10월**에 힘을 싣는다.

| 달 | 강도 | 주제 초점 |
|---|---|---|
| 2026-10 | 강 (추석 직후) | 가족 설득 1건 추가, 비용·환불 |
| 2026-11 | 보통 | 나라 순환, 절차 |
| 2026-12 | 보통 | 연말 결심형(내년 계획) 1건, 비자 |
| 2027-01 | 강 (설 전) | 자격·요건, 가족 설득 |
| 2027-02 | 강 (설 2월 6일 전후) | 비용, 사기 예방, 부모님께 |
| 2027-03 | 강 | 나라 순환 강화, 맞선 여행 |
| 2027-04 | 보통 | 절차·비자 |
| 2027-05 | 보통 | 가정의 달 — 결혼 후 생활·사후관리 |
| 2027-06 | 약 | 나라 순환 |
| 2027-07 | 약 | 비자·연장·영주 |
| 2027-08 | 강 (추석 준비) | 가족 설득, 60대 이상 사례 |
| 2027-09 | 강 (추석 9월 15일 전후) | 비용·환불, 사기 예방 |

강한 달은 발행을 앞당겨 명절 4주 전에 8건이 나가 있게 한다. 약한 달은 8건을 유지하되 갱신 글(오래된 글의 숫자 갱신, dateModified)로 채워도 된다.

## 4. 두 벌 쓰기 (홈페이지용 · 네이버 블로그용)

같은 주제를 한 벌로 복붙하면 유사문서로 묶인다. 구조와 문체를 다르게 쓴다.

| | 홈페이지 칼럼 | 네이버 블로그 원고 |
|---|---|---|
| 목적 | 구글·AI 검색 인용 | 네이버 검색·AI 브리핑 |
| 구조 | 질문형 H2 + 40~60자 두괄식 답 + 표 + 출처 | 이야기 흐름, 소제목, 사진 자리 안내 |
| 문체 | 담백한 설명체 | 대표가 말하는 듯한 구어체 |
| 스키마 | Article + dateModified | 없음(네이버 편집기) |
| 길이 | 1,500~2,500자 | 1,200~2,000자 |
| 연결 | 점검 위젯·상담 | 홈페이지 칼럼 링크·전화 |

네이버 블로그는 외부 AI 크롤러를 막는다. 챗GPT·퍼플렉시티에 인용되는 것은 홈페이지 칼럼이다. 그래서 홈페이지 쪽에 통계·출처·표를 몰아 넣는다.

## 5. 쓰지 않는 표현 (발행 전 검색)

결혼중개업법 제12조(거짓·과장 광고), 여성가족부 가이드라인, 변협 규정(전역 규칙 §23) 기준.

- 성혼 보장, 100%, 성사율, 실패 없음, 최고, 1위, 최저가, 무료(실제 무료가 아닌 것)
- 신부 후보, 신붓감, 순종적, 어리고 예쁜, 데려온다, 사온다, 고른다
- 도망, 먹튀, 위장결혼(사기 예방 글에서도 "이탈 위험"으로 바꿔 쓴다)
- 기간 확정("3개월이면 결혼"), 비용 확정("총 1,200만 원이면 끝")
- AI가 씁니다, 챗봇이 상담합니다 (AI 이용 사실을 광고하지 않는다)
- 확정 법률 판단("비자 나옵니다", "무효입니다"). "~에 해당할 수 있습니다"로.

발행 전 점검.
- [ ] 위 표현 검색 0건
- [ ] 숫자에 기준 연도와 출처가 붙어 있다 (소득 기준·환율·실태조사)
- [ ] 나라별 규정(캄보디아 만 50세 미만·월 2,550달러, 필리핀 이혼 제도 없음 등)이 최신인지 확인
- [ ] 업체가 실제로 진행하지 않는 나라를 "진행한다"고 쓰지 않았다
- [ ] 두 벌의 첫 문단이 서로 다르다
- [ ] 홈페이지 글에 점검 위젯 또는 상담으로 가는 링크가 있다

## 6. 알고 있어야 할 위험

- 2026년 검색 관심도는 2025년보다 약 40% 낮다(데이터랩 상대값, 2026년은 8월까지 집계). 검색이 유튜브·SNS로 옮겨 가고 있다. 블로그만으로 "결과로 증명"하기 어려울 수 있다.
- 대응 후보. 홈페이지 칼럼 하단에 영상 대본을 텍스트로 붙이기(AI가 읽을 데이터량 증가), 유튜브 대본 8건을 블로그 상품에 얹는 옵션. 반응을 보고 정한다.
- 우리가 써 준 글로 처분받는 것은 업체다(제27조 양벌규정). 발행 전 점검 책임과 범위를 계약서에 넣는다(가격 문서 §0.1의 미결 항목).
