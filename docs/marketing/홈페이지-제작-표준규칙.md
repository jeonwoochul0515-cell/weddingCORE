# 회원 업체 홈페이지 제작 — 표준 규칙 (2026-09-04)

weddingCORE가 회원 업체에 만들어 주는 홈페이지(마케팅 센터 「전환형 홈페이지 제작」, 회원 무료)의
공통 규칙이다. 업체가 누구든 손님은 같다. 손님 심리는 우리결혼중개 리서치
(`woori/docs/persona-research.md`, 2026-09-04)에서 왔고, 첫 적용 사례는 https://woori-wedding.com 이다.

한 줄로 손님이 원하는 것. **"들키지 않고 확인하고 싶다. 속지 않고 싶다. 사람답게 하고 싶다."**

## 0. 손님이 누구인가

여성가족부 「2023년 결혼중개업 실태조사」(2024-05, 국가승인통계) 기준.

| 항목 | 수치 | 설계에 주는 뜻 |
|---|---:|---|
| 40대 이상 | 86.5% | 글자 크게(본문 18px 이상), 한 손 조작 |
| 50세 이상 | 30.8% | 캄보디아 규정(만 50세 미만)에 셋 중 하나가 걸린다 |
| 월소득 300만 원 이상 | 63.9% | 소득보다 범죄경력·건강·혼인 정리가 실제 탈락 요인 |
| 업체를 안 경로 1위 온라인 광고 | 47.4% | 광고 유입 첫 화면이 곧 첫인상 |
| 지불 총액 평균 | 1,932만 원 | 비용을 숨기면 바로 의심한다 |
| 피해 유형 1위 계약해지·위약금 | 56.1% | 환불 조건이 신뢰의 핵심 |
| 검색의 모바일 비중 | 68~85% | 모바일 우선. 밤에 폰으로 본다 |

재혼 비율은 2012년 다문화가족실태조사의 26.3%가 자주 인용되나 낡은 수치다. 최신은 2021년 조사를 볼 것.

## 1. 규칙 열 가지

각 규칙은 「무엇을 / 왜 / 어떻게 / 점검」 순서다. 점검 항목은 제작 완료 전 전부 확인한다.

### R1. 판단하지 않는 얼굴
- 무엇을. 첫 화면 문장은 손님을 평가하거나 재촉하지 않는다.
- 왜. 손님은 국내 결혼시장에서 거절당한 경험을 안고 온다. "당신도 됩니다"는 의심을 키우고, "요건은 이것뿐입니다"는 안심시킨다.
- 어떻게. 히어로에 수치심을 푸는 한 문장. 화면 전반에서 "결정"을 "확인"으로 바꾼다. 격려 대신 객관적 요건을 보여 준다.
- 점검. 첫 화면에 "지금 결정", "서두르세요", "마지막 기회" 류가 없다.

### R2. 흔적 없음을 눈에 보이게
- 무엇을. 익명으로 물을 수 있다는 약속을 화면 상단에 배지로 둔다.
- 왜. 매매혼 낙인 때문에 결혼식까지 숨기는 손님이 있다. 위젯 안에만 적힌 약속은 못 본다.
- 어떻게. "실명 없이 상담 · 대화는 이 기기에만" 배지. 상담 캐릭터는 이름과 전화번호 이상을 묻지 않는다.
- 점검. 상담 입력란이 성함·연락처 두 칸뿐이다. 대화 저장은 선택 동의(기본 해제)다.

### R3. 숫자로 안심
- 무엇을. 비용 화면 맨 위에 "계약 전 비용 항목 전부 공개 · 환불·재매칭 조건 먼저" 카드와 등록번호.
- 왜. 피해 1위가 계약해지·위약금이다. 비용 항목을 숨기는 순간 사기 서사가 떠오른다.
- 어떻게. 항목별 금액 표(중개수수료·현지 비용·부대비용), 단계별 환불 조건 표, 결혼중개업 등록번호를 크게. weddingCORE 의무 템플릿의 「단계별 환불조건 명시」와 같은 표를 쓴다.
- 점검. 비용 페이지 첫 화면에 등록번호가 보인다. 환불 조건이 계약서와 같다(업체 확인).

### R4. 자격 먼저, 판매는 나중
- 무엇을. 홈의 첫 버튼은 「내 요건 2분 점검」, 그다음이 「상담 신청」.
- 왜. 손님의 첫 질문은 "나 같은 사람도 되나"다. 상담 신청부터 들이밀면 나간다.
- 어떻게. weddingCORE 빠른 점검 위젯(`https://weddingcore.net/embed/check?agency=<업체ID>&name=<업체명>`)을 iframe으로 심는다. 결과 화면에서 이름·연락처만 받아 업체 전화로 문자가 간다.
- 점검. 홈에서 스크롤 없이 점검 버튼이 보인다. 점검 결과가 업체 문자로 실제 도착한다.

### R5. 밤 모드
- 무엇을. 22~5시 방문 시 자동 저조도 화면. 낮에는 그대로.
- 왜. 잠복기 손님은 밤에 폰으로 본다. 흰 화면은 눈부시고 옆 사람에게 띈다.
- 어떻게. 디자인 토큰 한 벌 추가(종이색 → 먹색 바탕). 상담 캐릭터 첫마디도 시간대별.
- 점검. 새벽 1시에 열었을 때 어두운 화면이 뜬다. 대비(WCAG AA)가 유지된다.

### R6. 가족에게 보여 줄 한 장
- 무엇을. `/for-family` 페이지. 법·등록·절차·비용·사후관리·상대 존중 원칙을 A4 한 장 톤으로, 인쇄 버튼.
- 왜. 재혼과 자녀가 있는 손님이 많다. 부모·자녀·직장의 시선이 결정을 막는다.
- 어떻게. 사실만 적는다. 결혼중개업법 의무, 등록번호, 표준계약서, 혼인 전 재산약정(자녀·재산 정리)을 안내. 상담 캐릭터에 "부모님 설득" 대본.
- 점검. 페이지가 인쇄 시 한 장에 들어간다. 과장 표현이 없다.

### R7. 진행 현황판 (계약 손님용)
- 무엇을. 계약 손님이 문자 링크로 여는 화면. 단계 중 어디, 다음에 할 일, 대표 연락.
- 왜. "비행기를 타고 나니까 걱정이 되기 시작했다." 통제감을 잃는 순간 불안이 온다.
- 어떻게. weddingCORE 엔진이 제공한다(설계 `docs/진행-현황판-설계.md`). 홈페이지에는 링크만 둔다.
- 점검. 구현 전까지는 절차 페이지의 9단계 안내로 대신한다.

### R8. 사람으로 다루는 언어
- 무엇을. 상대 여성을 상품처럼 부르는 어휘를 쓰지 않는다.
- 왜. 손님 스스로 죄책감을 안고 온다. 상품 어휘는 그 죄책감을 건드리고 신뢰를 잃는다. 여성가족부 가이드라인과 결혼중개업법 제12조에도 걸린다.
- 어떻게. 아래 어휘표. 나라별 소개는 임금·물가·문화를 존중의 자료로 쓴다.
- 점검. 금지어 검색(grep)이 0건이다.

| 쓰지 않는 말 | 대신 쓰는 말 |
|---|---|
| 신부 후보, 신붓감, 여성 회원 명단 | 상대 분, 상대 여성 |
| 순종적, 착한, 어리고 예쁜 | (쓰지 않는다. 사람의 성격은 만나서 안다) |
| 데려온다, 사온다, 고른다 | 만난다, 소개받는다, 함께 정한다 |
| 성혼 보장, 100% 성사, 실패 없음 | 절차와 조건을 사실대로 |
| 도망, 먹튀, 위장 | 이탈 위험을 낮추는 절차(신상정보 교환·사전 교육) |
| AI가 상담, 챗봇에게 물어보세요 | 상담 실장(캐릭터 이름)에게 물어보기 — 변협 규정, 전역 규칙 §23 |

### R9. 명절 전후 캠페인
- 무엇을. 1~3월·8~10월에 칼럼·블로그 발행과 상담 캐릭터 첫마디를 계절 변형.
- 왜. 남성 관심도 최고월이 설·추석 앞뒤다. 가족 압박과 외로움이 겹친다.
- 어떻게. `docs/marketing/블로그-주제-달력.md`의 발행 시기를 따른다.
- 점검. 명절 4주 전에 그 달 원고가 준비돼 있다.

### R10. 모바일 우선 재점검
- 무엇을. 하단 고정 상담 버튼, 본문 18px 이상, 한 손 동선.
- 왜. 검색의 68~85%가 모바일이다.
- 어떻게. 375px 폭에서 전 화면 점검. 사진 없이도 화면이 성립하게.
- 점검. 라이트하우스 모바일 접근성 serious 0. 가로 스크롤 없음.

## 2. 사진 원칙

- 남의 결혼식·커플 사진을 쓰지 않는다. 손님은 남이 결혼하는 사진에 관심이 없다(대표 인사이트, 2026-09-03).
- 쓸 수 있는 것. 안내자(대표·사무소·상담실), 절차의 명료함(서류·도장·일정), 상대 나라의 거리와 생활, 손님 자신의 미래 생활.
- 생성 이미지를 실제 인물(대표·직원)로 쓰지 않는다. 성혼 사례는 실제 동의가 없으면 "예시(가상)"로 표시한다.
- 후기는 사진보다 "나와 비슷한 조건의 사람" 텍스트가 핵심이다. 나이대·지역·재혼 여부·걸렸던 점·걸린 기간.

## 3. 법 경계 (제작 전 업체와 확인)

- 결혼중개업법 제12조 거짓·과장 표시·광고 금지. "성혼 보장", "기간 확정", "추가 비용 0원", "재매칭 보장"은 **실제로 그렇게 운영하고 계약서에 있어야** 쓸 수 있다. 우리가 써 준 문구로 처분받는 것은 업체다(제27조 양벌규정).
- 여성 회원의 프로필·사진·외모·나이 묘사를 웹에 싣지 않는다.
- 변호사 제휴 표시는 변호사가 수위를 정한다. 법률 서비스 비용은 손님이 법률사무소에 직접 낸다. 업체는 대가를 받지 않는다(변호사법 제34조).
- 상담 캐릭터가 먼저 "저는 AI입니다"라고 밝히지 않는다. 물으면 사실대로 답한다(전역 규칙 §23).

| 나라별 안내 | 임금·물가·문화·혼인 관습·현지 규정(캄보디아 나이·소득 등), 사진 없음 | R8 |

## 5. 제작 전에 업체에서 받을 것

1. 결혼중개업 등록번호와 등록증 사본 (화면 표시용)
2. 손해배상책임보험 가입 여부 (1억 원 이상)
3. 비용 항목표와 단계별 환불 조건 (계약서와 같아야 한다)
4. 실제로 진행하는 나라 목록과 가장 많은 나라 (지어내지 않는다)
5. 대표 사진 제공 여부 (없으면 사무소·상담실 사진으로)
6. 실제 동의받은 성혼 사례 유무 (없으면 예시로 표시)
7. 상담 문자를 받을 전화번호 (weddingCORE 업체 문서의 전화번호와 같게)

## 6. 검색·AI 노출 최소 세트

전역 가이드(`SEO_GEO_AEO_최적화_가이드.md`, `NAVER_SEO_최적화_가이드.md`)를 따르되 다음은 빠뜨리지 않는다.

- 프리렌더로 본문을 정적 HTML에 넣는다. IndexNow를 배포 스크립트 끝에 붙인다.
- `LocalBusiness` + `sameAs`(플레이스·카톡채널·블로그), `FAQPage`, `BreadcrumbList`, 칼럼은 `Article` + `dateModified`.
- AI 검색봇(OAI-SearchBot·ChatGPT-User·PerplexityBot·Claude 검색봇) 허용.
- 대표 키워드 5개는 나라+국제결혼, 지역+국제결혼, 재혼국제결혼 축으로. 나이 키워드는 검색량이 없다(월 20 이하).

## 부록 A. AEO 핵심 질문 20개 (여정 순서)

AEO·GEO 상품(핵심 질문 20개 구조화)의 기본 목록이다. 업체 사정에 맞게 바꾸되 여정 순서는 유지한다.
각 답은 40~60자 두괄식으로 먼저 답하고 부연한다. 결과·기간·금액을 단정하지 않는다.

| 단계 | 질문 |
|---|---|
| 잠복 | 1. 국제결혼은 어떤 사람이 하나요 |
| 잠복 | 2. 40대·50대 재혼도 국제결혼이 가능한가요 |
| 자격 | 3. 국제결혼을 하려면 어떤 조건이 필요한가요 |
| 자격 | 4. 소득이 얼마나 있어야 결혼이민(F-6) 비자가 나오나요 |
| 자격 | 5. 범죄경력이나 이전 초청 이력이 있으면 어떻게 되나요 |
| 비용 | 6. 국제결혼 비용은 총 얼마이고 무엇이 포함되나요 |
| 비용 | 7. 계약 후 추가로 붙는 비용이 있나요 |
| 비용 | 8. 중간에 그만두면 환불이 되나요 |
| 사기 | 9. 국제결혼 사기를 피하려면 무엇을 확인해야 하나요 |
| 사기 | 10. 등록된 중개업체인지 어떻게 확인하나요 |
