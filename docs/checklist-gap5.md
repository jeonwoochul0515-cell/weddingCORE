# 체크리스트 — 해외 SaaS에 있고 우리에 없던 다섯 가지 (2026-09-06)

근거: `docs/해외SaaS-기능비교-2026-09-06.md`. 순서는 값싼 것과 의존 관계를 함께 본다.

## A. 직원 초대·권한 (가장 값싸다 — 저장 규칙이 이미 있다)
- [x] 업체 정보에 「직원」 탭 — 구성원 목록(이름·역할·상태)
- [x] 대표가 이메일로 초대하면 `agencies/{aid}/invites/{email}`에 남는다
- [x] 초대된 이메일로 가입하면 서버 함수가 그 업체 직원으로 붙인다(커스텀 클레임)
- [x] 역할 바꾸기·내보내기(대표만)
- [x] 규칙: invites 읽기/쓰기, members 역할 변경
- [x] 대표 계정은 스스로 내보낼 수 없다

## B. 사진
- [x] 고객 프로필에 사진 한 장 — 등록·수정 창 맨 위에 붙였고 상세 화면 이름 옆에 보인다
- [x] 후보 프로필에 사진 한 장
- [x] Storage 규칙: `agencies/{aid}/photos/{종류}/{id}/{파일}`
- [x] 5MB 제한, 이미지만, 지우기 가능

## C. 후보 명부 (B에 기댄다)
- [x] `agencies/{aid}/partners/{partnerId}` — 고객에 매달리지 않는 독립 명부
- [x] 화면 `/agency/partners` — 목록·검색·거르기(국적·나이·상태)
- [x] 등록·수정·지우기(확인 단계)
- [x] 상태: 소개 가능 / 소개 중 / 성사 / 중단
- [x] 고객 상세의 매칭에서 이 명부에서 골라 넣는다(이름 타이핑 없애기)
- [x] 규칙·색인

## D. 인쇄물
- [x] 신상정보 서면 인쇄 (`/agency/clients/:id/background-info` → 인쇄 보기)
- [x] 후보 프로필 인쇄 (사진 포함)
- [x] A4 기준, 인쇄 시 화면 장식 숨김

## E. 계약서 초안
- [ ] 법 제10조가 요구하는 항목을 빠짐없이 담는 서식 — **못 했다.** 조문 원문을 공개 경로로
      받지 못했다(법제처 API는 등록 IP만 받는다). 확인된 항목만 담고 화면에 초안임을 밝혔다.
      시행규칙 별표를 받아 항목을 대조하는 일이 남았다
- [x] 업체 정보·고객 정보는 이미 있는 값으로 채운다
- [x] 수수료·환불조건은 대표가 입력
- [x] **초안임을 명시하고 변호사 검토를 거치도록 표시**(전역 §21)
- [x] 인쇄 가능

## 고치는 중에 나온 다른 결함

### 업무 공간의 모든 팝업이 화면 밖에 떴다
「정보 수정」을 눌러도 창이 안 보였다. 화면 겉틀(AppLayout)에 걸린 등장 애니메이션이
끝난 뒤에도 이동값을 남겨 두어서, 그 겉틀이 팝업의 기준 상자가 되어 있었다.
팝업 크기를 재 보니 화면 크기(1707×842)가 아니라 문서 전체(1365×3810)였다.
짧은 화면에서는 우연히 맞아 보이지만 고객 상세처럼 긴 화면에서는 보이지 않는 곳에 뜬다.
`src/styles/globals.css`의 `animate-rise`를 고쳤다(근거는 그 파일 주석).
