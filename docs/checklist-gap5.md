# 체크리스트 — 해외 SaaS에 있고 우리에 없던 다섯 가지 (2026-09-06)

근거: `docs/해외SaaS-기능비교-2026-09-06.md`. 순서는 값싼 것과 의존 관계를 함께 본다.

## A. 직원 초대·권한 (가장 값싸다 — 저장 규칙이 이미 있다)
- [ ] 업체 정보에 「직원」 탭 — 구성원 목록(이름·역할·상태)
- [ ] 대표가 이메일로 초대하면 `agencies/{aid}/invites/{email}`에 남는다
- [ ] 초대된 이메일로 가입하면 서버 함수가 그 업체 직원으로 붙인다(커스텀 클레임)
- [ ] 역할 바꾸기·내보내기(대표만)
- [ ] 규칙: invites 읽기/쓰기, members 역할 변경
- [ ] 대표 계정은 스스로 내보낼 수 없다

## B. 사진
- [ ] 고객 프로필에 사진 한 장 (`ClientProfile.photoPath`)
- [ ] 후보 프로필에 사진 한 장
- [ ] Storage 규칙: `agencies/{aid}/photos/{종류}/{id}/{파일}`
- [ ] 5MB 제한, 이미지만, 지우기 가능

## C. 후보 명부 (B에 기댄다)
- [ ] `agencies/{aid}/partners/{partnerId}` — 고객에 매달리지 않는 독립 명부
- [ ] 화면 `/agency/partners` — 목록·검색·거르기(국적·나이·상태)
- [ ] 등록·수정·지우기(확인 단계)
- [ ] 상태: 소개 가능 / 소개 중 / 성사 / 중단
- [ ] 고객 상세의 매칭에서 이 명부에서 골라 넣는다(이름 타이핑 없애기)
- [ ] 규칙·색인

## D. 인쇄물
- [ ] 신상정보 서면 인쇄 (`/agency/clients/:id/background-info` → 인쇄 보기)
- [ ] 후보 프로필 인쇄 (사진 포함)
- [ ] A4 기준, 인쇄 시 화면 장식 숨김

## E. 계약서 초안
- [ ] 법 제10조가 요구하는 항목을 빠짐없이 담는 서식
- [ ] 업체 정보·고객 정보는 이미 있는 값으로 채운다
- [ ] 수수료·환불조건은 대표가 입력
- [ ] **초안임을 명시하고 변호사 검토를 거치도록 표시**(전역 §21)
- [ ] 인쇄 가능
