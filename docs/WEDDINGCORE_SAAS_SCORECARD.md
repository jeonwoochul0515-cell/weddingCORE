# WeddingCORE SaaS 출시 점수표

목표는 결혼중개업체가 영업에 집중하고, 반복 문서업무는 AI·규칙엔진이 처리하며,
법률 판단은 변호사가 독립적으로 검토·승인하는 것입니다. 총 100점 중 95점 이상을
출시 후보 기준으로 삼습니다. 보안 필수항목 실패 시 점수와 관계없이 94점 이하입니다.

## 평가 배점

| 영역 | 배점 | 합격 조건 |
|---|---:|---|
| 업체 자동화 흐름 | 25 | 고객 선택, 동의, 문서 유형, 캐럿, 작업 이력 |
| 변호사 검토 흐름 | 15 | 분리된 검토 큐, 승인·수정요청, 상태 전이, 감사 기록 |
| 보안·개인정보 | 30 | 역할/소속 불변, 테넌트 격리, 익명 저장 금지, 동의 게이트, App Check, 입력 제한 |
| 법률정보 안전성 | 10 | 2026 공식 소득기준, 출처 링크, 가짜 고시·임시 수치 없음 |
| 현장 사용성 | 10 | 사이드바 진입, 고객 상세 바로가기, 상태·면책 안내 |
| 검증·문서화 | 10 | 웹 타입검사, 함수 빌드, 운영 설정 문서 |
| 합계 | 100 | 95점 이상 + 보안 필수항목 전부 통과 |

## 운영상 사람의 승인 경계

- AI 결과는 항상 초안이며 고객 교부·관공서 제출에 바로 사용할 수 없습니다.
- 업체는 고객의 실제 서면 또는 전자동의 증빙 위치를 기록해야 합니다.
- 변호사는 원자료와 최신 법령을 대조한 뒤 승인하거나 수정 요청합니다.
- 공시 인증과 출입국민원 대행 표시는 실제 등록·검증 완료 전 활성화하지 않습니다.
- AI 사용 단위는 캐럿이며 문서 유형별 고정 비용입니다. AI 장애 시 자동 복구합니다.
- 월간 기본 제공량은 무상 보장이 아니라 운영 정책값입니다. 요금제 개편·비용 구조에 따라
  사전 고지 후 축소하거나 유료 전환할 수 있으며, 화면과 안내문에 무료 제공량을 확정 약속처럼
  표기하지 않습니다. 조정은 `AI_MONTHLY_ALLOWANCE` 환경변수 또는 업체별 `aiCredits.monthlyAllowance`로 합니다.

## 배포 전 필수 운영 설정

1. Firebase App Check reCAPTCHA Enterprise 키 설정
2. `ANTHROPIC_API_KEY` Secret 및 사용할 모델명 검증
3. Firestore·Storage 보안 규칙과 인덱스 배포
4. 변호사 계정 Custom Claims를 관리자 경로로만 부여
5. 개인정보 처리방침·제3자 제공 동의서의 실제 수임 구조 반영 및 변호사 확정
6. 에뮬레이터 권한 회귀 테스트와 실제 스테이징 테스트 수행
